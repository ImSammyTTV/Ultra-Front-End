## What's new in 1.2.12

**Emulators**
- BIOS files are set up for the emulator you actually use, and RetroArch gets them for every console
- An emulator moved by an update keeps working
- Installs no longer report a failure while a quiet installer is still working
- Zipped games unpacked for playing are cleared away once you stop playing them, so they don't fill your drive

**More dependable**
- Bluetooth pairing gives up quickly with a message when a device doesn't answer
- Renames, art changes and playtime are never lost when two happen at once
- Games nobody has written about aren't looked up again at every start
- Updates wait for a new version that's slow to start, and work on PCs that block PowerShell

**Safer**
- Other websites can't reach Ultra Front End or show it inside their own pages

**Everything else**
- Uninstalling with Delete my settings removes them wherever they're kept
- Downloading a release over a dev build takes you back to Main
