## What's new in 1.2.11

**Use it as your wallpaper**
- Ultra Front End can run as a Wallpaper Engine wallpaper: browse and start games right from the desktop with a controller, the mouse or the keyboard (Settings › General)

**Your games**
- Rockstar Games Launcher games are found by themselves
- Shortcuts to Microsoft Store and Game Pass games show up as games
- Steam games that are updating still show as installed
- Disc games kept beside a playlist no longer go missing, and update and add-on files no longer show as games of their own
- Games with titles in other alphabets, or two games that share a name, no longer disappear

**Playing**
- Playtime is right for Battle.net, GOG Galaxy and Rockstar games, and after a crash or a shutdown mid-game
- A game that needs administrator rights asks once and starts once
- Games that run in a console window start with it showing
- The controller's guide button works straight away after starting the PC, while your library loads

**Settings that stay put**
- Settings can no longer be lost when another program is busy with the file, or after a power cut
- Changes made while an emulator installs are kept

**Everything else**
- Wi-Fi in Quick Access works in every Windows language
- Videos export from the album again
- Updates never install over another app you're using, and the frontend opens again if one doesn't go in
- News pictures fill their cards
- An emulator whose project moved installs again
- The daily usage count is gone: nothing is sent from your PC
- Lots of smaller fixes, and a new wiki with a page for each part of the app
