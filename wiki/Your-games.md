# Your games

## Found by themselves

Installed games from **Steam, Epic Games, EA app, Ubisoft Connect, GOG, Rockstar Games and Battle.net** show up on
their own. Store games start through their own launcher, so sign-in, updates and cloud saves still work.

A Steam game that's being updated still counts as installed, so it shows **Play**, not **Install**.

## Accounts (Settings › Accounts)

- **Steam:** your profile link and a free Steam Web API key bring in games you own but haven't installed, with playtime and achievements.
- **Epic Games:** sign in on Epic's own site; the frontend never sees your password.
- **SteamGridDB** (optional): more artwork to choose from. See [Artwork and game info](Artwork-and-game-info.md).
- **RetroAchievements** (optional): achievements for emulated games.

Select a connected account twice to disconnect it.

## Your own games (Settings › Libraries)

- **Add a folder of PC games:** each folder in it is a game. Shortcuts (`.lnk`, `.url`) in it count too.
- **Add a ROM folder and emulator**, for a console outside your ROMs folder.
- **Add a single game:** one program, game or launcher.
- **Add a folder:** a tile that opens any folder (films, tools).

New games dropped into a library or the ROMs folder appear by themselves. A big batch shows an **Updating your library**
window with its progress; press **A** or **B** to keep browsing while it finishes.

## Renaming a game

**Y › Rename** on a game. Type the name and choose **Done**: a list of the games Wikipedia knows by that name appears
("Super Mario Bros. Wonder · 2023 video game"). Pick yours and the game takes that name, with its description, genre,
developer, year and trailer from that article from then on. **Just call it "…"** keeps the name exactly as you typed it.

## Favourites, collections and hiding

- **Favourites:** **Y › Collections › Favourites**. They get a tab of their own.
- **Collections:** your own groups of games, in the same menu.
- **Hide this game:** takes it off every tab. Find it again in **Settings › Hidden games**.

## Search

The **Search** button, or just start typing on the Library page. With a controller, use the on-screen keyboard.
