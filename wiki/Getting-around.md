# Getting around

## The home screen

- **The row** holds your games, the ones you played last first. New games show up here by themselves.
- **The tabs** along the bottom (All Games, Favourites, then each platform) choose what the row shows.
- **The round buttons** open the **Library**, **Emulators**, **Album**, **Search**, **News** and **Settings**.
- **Full-screen game art** (Settings › General) puts the selected game's background behind everything.

## Controls

| Button | Home screen | In a game |
|---|---|---|
| **A** / **B** | Select / Back | |
| **Y** or **Start** | Game menu | |
| **View** | Quick Access | |
| **LB** / **RB** | Change tab | |
| **Xbox**, **Steam** or **View + Start** | Open the frontend | In-game menu |
| **View + RB** | | Screenshot |
| **View + LB** | | Start or stop recording |

A keyboard (arrow keys, **Enter**, **Esc**), a mouse and touch screens work too. On the Library page, just start typing
to search. Text fields open an on-screen keyboard you can use with the controller.

Xbox-style controllers, DualSense, DualShock 4, Switch Pro controllers and the Steam Controller all work. Check yours in
**Settings › Controllers › Controller tester**.

## A game's page

Select a game to open its page: its art, description, playtime, achievements, screenshots, trailers and news. **Play**
starts it; **⋯** has more.

## The game menu (Y)

Press **Y** (or **Start**) on a game for:

- **Game details**
- **Collections** and **Favourites**
- **Artwork:** change the cover, logo or background (see [Artwork and game info](Artwork-and-game-info.md))
- **Rename:** type a name, then pick the game from the list so its info is right (see [Your games](Your-games.md))
- **Hide this game**
- **App location** (PC games): point it at a different program

## Quick Access (View)

A panel on the right with the clock, volume and sound output, music controls, Wi-Fi, Bluetooth, controller batteries,
friends, downloads, and the power options (Sleep, Restart, Shut down, Exit). Restart and Shut down ask for a second press.

## The in-game menu

Press **Xbox**, **Steam** or **View + Start** in a game started from the frontend. It has volume, music, screenshots,
recording, the performance overlay and **Close game**. While it's open, your controller works the menu, not the game.
